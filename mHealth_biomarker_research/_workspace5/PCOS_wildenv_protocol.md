## 1. 설계 철학

### 1-1. 왜 통제 환경 프로토콜이 In-the-Wild 연구에 맞지 않는가

기존 임상 프로토콜(v1.0)은 "완벽한 조건"을 사전에 달성하도록 요구한다. 그러나 일상 모니터링 연구에서 이 방식은 다음 문제를 낳는다:

- **순응도 붕괴**: 매번 엄격한 수칙을 지켜야 하면 장기 참여율이 급감한다. EMA 메타분석에서 6개월 누적 순응도는 통제 조건이 엄할수록 하락한다 [[4]](#ref4)
- **선택 편향**: 조건을 충족할 수 있는 시간·장소에서만 측정 → 사용자의 실제 일상 상태가 아닌 최상의 상태만 수집됨
- **생태학적 타당성 손상**: 임상시험 목표가 "일상에서의 PCOS 예측"인데, 수집 데이터는 일상을 반영하지 않음

### 1-2. 대안 패러다임: 노이즈를 제거하는 대신 측정한다

| 전통 접근               | In-the-Wild 접근                  |
| ------------------- | ------------------------------- |
| 노이즈 발생 조건을 사전에 금지   | 노이즈 발생 여부를 측정하고 기록              |
| 조건 미충족 시 데이터 수집 거부  | 모든 데이터 수집 + 품질 등급(A/B/C) 부여     |
| 동질한 조건으로 일반화        | 환경 다양성이 모델 강건성 향상               |
| 사전 통제 (pre-capture) | 사후 보정 (post-capture adjustment) |

> **근거**: Ali et al.(2026)은 별도 지시 없이 환자가 자가 촬영한 사진 중 **94.6%가 임상 결정에 충분한 품질**임을 확인했다. 완벽한 통제 없이도 다수의 데이터가 활용 가능하다 [[11]](#ref11).  
> Vekony et al.(2024)도 "지시 없는 셀카"가 원격 피부과 진료에 충분한 품질이었음을 보고했다 [[12]](#ref12).

## 2. 노이즈 변수

In-the-Wild 환경에서 발생하는 노이즈를 **통제 불가·부분 통제 가능·수집 가능 메타데이터**로 분류한다.

---

### 2-A. rPPG (혈류 신호) — In-the-Wild 노이즈

| 노이즈 변수                     | 발생 빈도       | 통제 가능성        | In-the-Wild 영향      | 대응 전략                            |
| -------------------------- | ----------- | ------------- | ------------------- | -------------------------------- |
| **형광등·LED 플리커**            | 실내 어디서나     | 통제 불가         | 50/60 Hz 간섭 → 가성 피크 | AE/AWB 잠금 + FFT 필터링 [[1]](#ref1) |
| **자동 노출(AE) 변동**           | 항상 발생       | 부분 통제 (잠금 가능) | 픽셀 강도 변동이 맥박 신호 혼동  | 앱에서 촬영 시작 즉시 AE 잠금 [[1]](#ref1)  |
| **자동 화이트밸런스(AWB)**         | 항상 발생       | 부분 통제 (잠금 가능) | RGB 채널 비율 실시간 변경    | 앱에서 AWB 잠금 [[1]](#ref1)          |
| **혼합·변동 조명**               | 매우 흔함       | 통제 불가         | 색온도 불안정             | 조명 불안정도를 메타데이터로 기록               |
| **직사광선**                   | 야외 촬영 시     | 통제 불가         | 피부 포화 → 신호 클리핑      | 과다 노출 감지 시 경고 + 재촬영 권유           |
| **핸드헬드 손 떨림**              | 삼각대 없을 때 항상 | 통제 불가         | 모션 아티팩트             | 광학식손떨림보정(OIS) + 소프트웨어 안정화        |
| **배경 움직임**                 | 공공장소·TV·가족  | 통제 불가         | ROI 추출 교란           | 얼굴 ROI 추적 알고리즘 고도화 [[1]](#ref1)  |
| **VFR (가변 프레임레이트)**        | 기기 부하 시 발생  | 부분 통제         | 시계열 불균일             | 앱 레벨에서 30 fps 강제 설정 [[1]](#ref1) |
| **운동 직후 상태**               | 예측 불가       | 통제 불가         | 심박수 상승·발적·발한        | 측정 시점 활동 수준을 자가보고로 수집            |
| **카페인·알코올**                | 예측 불가       | 통제 불가         | HRV 변동              | 측정 전 섭취 여부를 자가보고로 수집             |
| **감정 상태**                  | 예측 불가       | 통제 불가         | 교감신경 활성화 → HRV 억제   | 측정 전 기분/스트레스 1–5점 자가보고           |
| **메이크업 착용**                | 일상에서 매우 흔함  | 참여자 선택        | 피부 반사율 변화           | 메이크업 여부를 메타데이터로 기록 [[5]](#ref5)  |
| **피부톤 (Fitzpatrick 4–6형)** | 개인 특성       | 통제 불가         | G채널 SNR 저하          | 피부톤별 보정 알고리즘 적용 [[7]](#ref7)     |

| 노이즈 변수                 | 발생 빈도         | 통제 가능성 | 영향                | 대응 전략                                    |
| ---------------------- | ------------- | ------ | ----------------- | ---------------------------------------- |

| **역광**                 | 야외·창가         | 통제 불가  | 얼굴 전면 노출 부족       | 과소 노출 감지 → 즉시 재촬영 경고                     |

| **두상 자세 변동**           | 매우 흔함         | 부분 통제  | 비대칭·뷰 불일치         | FAIN 자동 정렬 보조 + 자세 추정 메타데이터 [[3]](#ref3) |
| **초점 불량**              | 이동 중·흔들림 시    | 부분 통제  | 병변 유형 식별 불가       | Laplacian 분산 측정 → 블러 등급 메타데이터            |
| **메이크업 착용**            | 일상에서 매우 흔함    | 참여자 선택 | 여드름·피부톤 가림        | 메이크업 여부 메타데이터 + 별도 분석 코호트 [[5]](#ref5)   |
| **기상 직후 부종**           | 아침 촬영 시       | 통제 불가  | 안와 부종, 얼굴 형태 변화   | 촬영 시각 자동 기록 (시간대 메타데이터)                  |
| **무표정 유지 실패**          | 자연스러운 표정 촬영 시 | 부분 통제  | 비대칭·근육 수축 변화      | 표정 감지 알고리즘으로 중립 표정 자동 선택                 |
| **배경 복잡성**             | 공공장소 항상       | 통제 불가  | 배경 분할 어려움         | 포트레이트 모드 또는 배경 분할 알고리즘                   |

## 3. 최소 요구 조건 (Minimum Viable Requirements)

통제 불가 환경에서도 데이터를 사용하기 위한 **절대 최솟값**만 설정한다. 이 조건만 충족하면 촬영을 허용하고, 나머지 조건은 메타데이터로 수집한다.

### 3-1. 절대 거부 조건 (Data Reject — 이 경우에만 재촬영 요청)

| 조건                   | 판정 기준             | 앱 메시지                                   |
| -------------------- | ----------------- | --------------------------------------- |
| **얼굴 미검출**           | 얼굴 랜드마크 미검출       | "얼굴이 보이지 않습니다. 카메라를 얼굴 앞에 위치해 주세요."     |
| **극단적 과다 노출**        | 히스토그램 포화 > 40%    | "너무 밝습니다. 조명에서 조금 멀어지거나 그늘진 곳으로 이동하세요." |
| **극단적 블러**           | Laplacian 분산 < 20 | "너무 흔들렸습니다. 잠깐 멈추고 다시 촬영하세요."           |
| **얼굴 크기 부족**         | 화면 < 15% 점유       | "더 가까이 다가와 주세요."                        |
| **동영상 길이 부족** (rPPG) | 15초 미만            | "조금 더 기다려 주세요."                         |
|                      |                   |                                         |

> **근거**: Ali et al.(2026)에서 별도 지시 없는 자가촬영의 94.6%가 임상 활용 가능한 수준이었음 → 절대 거부 조건을 매우 느슨하게 설정해도 대부분 데이터 활용 가능 [[11]](#ref11)

### 3-2. 품질 등급 (Reject 없이 등급만 부여)

절대 거부 조건 외의 모든 데이터는 수집하되, 아래 5개 기준으로 **품질 등급 A/B/C**를 자동 부여한다.

| 기준 | A (최고) | B (양호) | C (저품질, 보정 필요) |
|------|---------|---------|-------------------|
| 조도 (lux) | 400–1,200 | 200–400 or 1,200–2,000 | < 200 or > 2,000 |
| 블러 (Laplacian) | ≥ 100 | 50–100 | 20–50 |
| 얼굴 자세 (yaw) | ±10° | ±20° | ±30° |
| 조명 균일도 | 그림자 없음 | 약한 그림자 | 강한 그림자·역광 |
| 메이크업 | 없음 | 가벼운 메이크업 | 두꺼운 파운데이션 |

> **분석 전략**: 1차 분석은 A등급만, 2차 분석은 A+B, 3차는 전체 데이터. 분석 민감도 비교 [[9]](#ref9)

## 4. 실시간 환경 품질 피드백 시스템 (앱 내)

통제 불가 환경에서는 **사전 금지** 대신 **촬영 시점의 실시간 피드백**이 핵심이다.

### 4-1. 시각적 실시간 피드백 (촬영 전)

```
┌─────────────────────────────────┐
│  [얼굴 가이드 오버레이]           │
│  ● 조도: 🟡 보통 (320 lux)       │  → 클릭 시 "더 밝은 곳이면 더 좋아요"
│  ● 떨림: 🟢 안정              │
│  ● 자세: 🔴 고개 왼쪽          │  → "오른쪽으로 살짝 돌려주세요"
│  ● 초점: 🟢 선명              │
│                                 │
│  [C등급으로도 촬영 가능합니다]    │  ← 핵심 UX: 거부 대신 안내
│  [최적 조건에서 촬영] [지금 촬영] │
└─────────────────────────────────┘
```

- **핵심 원칙**: "촬영 불가" 대신 "현재 조건 등급 + 지금도 촬영 가능" 제공
- 사용자가 최적 조건을 선택하거나, 현재 조건 그대로 촬영할 수 있음
- 근거: Vodrahalli et al.(2023) — 단순 거부보다 구체적 개선 안내가 품질 향상에 효과적 [[9]](#ref9)

### 4-2. rPPG 전용: 이동 중·활동 중 감지 및 대기

```
사용자가 걷거나 이동 중임이 감지되면:
→ "잠깐 멈추면 더 정확해요. 준비되면 [시작] 누르세요."
→ 즉시 촬영도 허용 (이동 상태를 메타데이터로 기록)
```

- 가속도계 데이터로 이동 여부 자동 감지
- 근거: MobilePhys(2022) — 모션 아티팩트를 소프트웨어로 보정 가능함을 입증 [[1]](#ref1)

### 4-3. 자동 최적 순간 포착 (Auto-Best-Frame)

30초 영상에서 전체를 분석하되, **품질 최상위 구간만 추출**하여 분석에 사용.

- rPPG: 30초 수집 → 모션 아티팩트·조명 급변 구간 제외 → 실제 분석 구간 자동 선택
- 사진: 3장 연속 촬영 → 블러·자세 기준 최적 1장 자동 선택
- 근거: Vodrahalli et al.(2023) — 여러 장 중 최선 이미지 선택 전략 채택 [[9]](#ref9)

## 5. 데이터 품질 메타데이터 자동 수집

**"통제하지 않는다"는 것은 "기록하지 않는다"는 것이 아니다.**  
모든 촬영에서 아래 메타데이터를 자동·반자동으로 수집하여 분석 단계에서 보정 변수로 활용한다.

### 5-1. 자동 수집 (앱이 자동 기록)

| 메타데이터 | 측정 방법 | 활용 |
|----------|---------|------|
| **촬영 시각** (hh:mm) | 시스템 시계 | 시간대별 피지·부종 패턴 보정 |
| **조도** (lux) | 조도 센서 | 조명 등급 분류 |
| **색온도 추정** | AWB 값 역산 | 조명 유형 분류 |
| **블러 지수** (Laplacian 분산) | 이미지 처리 | 초점 품질 등급 |
| **얼굴 자세** (yaw/pitch/roll) | 랜드마크 추정 | 각도 보정 |
| **이동 여부** | 가속도계 | rPPG 모션 보정 |
| **화면 내 얼굴 크기** | 랜드마크 간 거리 | 촬영 거리 추정 |
| **그림자 유무** | 얼굴 조도 불균일도 | 조명 방향 분류 |
| **GPS 위치 유형** (실내/야외) | GPS + 기압계 | 환경 유형 분류 |

### 5-2. 참여자 자가보고 (10초 이내 완료)

| 항목            | 형태     | 선택지                   |
| ------------- | ------ | --------------------- |
| **메이크업 여부**   | 아이콘 선택 | 없음 / 가벼움 / 두꺼운 파운데이션  |
| **월경 주기 일차**  | 숫자 입력  | 1–35일 / 모름 / 현재 월경 중  |
| **지난 2시간 활동** | 아이콘 선택 | 안정 / 보행 / 운동 / 격렬한 운동 |
| **기분·스트레스**   | 슬라이더   | 1 (매우 편안) – 5 (매우 긴장) |
| **카페인 섭취**    | 토글     | 2시간 이내 섭취 여부          |

> **근거**: Apple Women's Health Study(50,000+ 참여자)에서 짧은 자가보고 설문이 장기 순응도를 유지하면서 풍부한 메타데이터를 수집하는 핵심 방법임을 입증 [[10]](#ref10)

### 5-3. 메타데이터 기반 데이터 계층화

```
수집된 모든 데이터
    ├── Tier A: 조도 400+ / 블러 100+ / 자세 ±10° / 메이크업 없음 / 안정 상태
    ├── Tier B: 위 조건 2–3개 충족
    └── Tier C: 1개 이하 충족 (보정 후 분석 또는 민감도 분석용)
```

## 6. 노이즈 보정 전략 (모델·분석 단계)

사전 통제 대신, **데이터 수집 후 알고리즘적 보정**으로 품질 격차를 좁힌다.

### 6-1. rPPG 노이즈 보정

| 노이즈 | 보정 방법 | 근거 |
|--------|---------|------|
| **조명 플리커** | FFT에서 50/60 Hz 노치 필터 적용 | [[1]](#ref1) |
| **모션 아티팩트** | 광학 흐름(Optical Flow) 기반 모션 추정 후 제거 | [[1]](#ref1) |
| **AE/AWB 변동** | 촬영 시작 시 AE/AWB 잠금 (앱 강제) | [[1]](#ref1) |
| **피부톤 차이** | Fitzpatrick 그룹별 채널 가중치 보정 | [[7]](#ref7) |
| **메이크업** | 메이크업 유무를 보조 변수로 회귀 보정 | [[5]](#ref5) |
| **감정·활동 상태** | 자가보고 스트레스·활동 수준을 공변량으로 투입 | [[4]](#ref4) |

### 6-2. 안면 분석 노이즈 보정

| 노이즈 | 보정 방법 | 근거 |
|--------|---------|------|
| **조명 방향 비대칭** | Retinex 조명 정규화 또는 GAN 기반 조명 통일화 | [[2]](#ref2) |
| **각도 변동** | 3D 얼굴 모델 피팅 → 정면 뷰로 재투영 | [[3]](#ref3) |
| **색온도 변화** | 색표 스티커 기준 화이트밸런스 사후 보정, 또는 AWB 잠금 [[13]](#ref13) | |
| **카메라 거리** | 안간거리 기준 픽셀 크기 역산 → 실제 크기 추정 | [[3]](#ref3) |
| **메이크업** | 메이크업 유무를 분석 층화 변수로 활용 | [[5]](#ref5) |
| **블러** | Deblurring 알고리즘 전처리, 또는 등급 B 이상만 사용 | [[9]](#ref9) |

### 6-3. 데이터 충분성 전략: 반복 측정으로 노이즈 평균화

- 단일 측정의 노이즈보다 **반복 측정의 평균·추세**가 더 신뢰성 높음
- 수집 빈도: 하루 1회 → **30일 누적 시 단일 측정 대비 신뢰도 대폭 향상**
- 근거: EMA 메타분석 — 반복 측정 설계가 일회성 임상 측정보다 생태학적 타당성 높음 [[4]](#ref4)

## 7. 참여자 최소 지시사항

통제 환경 프로토콜의 엄격한 금지 목록 대신, **"할 수 있을 때는 이렇게 하면 더 좋아요"** 수준의 부드러운 권장 사항만 제공한다.

---

### 7-1. 절대 요청 사항 (반드시 따라야 함 — 3가지만)

> 앱 내 온보딩 화면에서 강조 표시

```
1. 얼굴이 화면에 크게 보이도록 해 주세요.
2. 촬영 중에는 최대한 움직이지 않도록 해 주세요.
3. 촬영 전에 표시등 색깔을 확인해 주세요.
   (빨강: 다시 시도 / 노랑·초록: 모두 촬영 가능)
```

---

### 7-2. 권장 사항 (따르면 데이터 품질이 높아집니다 — 강요하지 않음)

아래 내용은 앱의 "팁" 섹션에서 제공. 촬영 전 팝업이 아닌, 참여자가 원할 때 확인하는 방식.

**조명에 대해**
> "형광등이나 LED 조명이 켜진 실내, 또는 그늘진 창가가 가장 좋아요. 햇빛이 직접 얼굴에 닿는 곳은 피해주세요."  
> *(참조: MDedge 피부과 사진 가이드라인* [[2]](#ref2) */ SkinTracker 연구* [[5]](#ref5)*)*

**세안에 대해**
> "메이크업을 하셨어도 괜찮아요. 다만 메이크업 여부는 앱에서 선택해 주세요."  
> *(참조: SkinTracker 연구에서 메이크업 착용 상태를 메타데이터로 기록* [[5]](#ref5)*)*

**활동에 대해**
> "운동 직후라면 5분 정도 앉아서 쉬고 촬영하면 더 좋아요. 바쁠 땐 바로 촬영해도 됩니다."  
> *(참조: rPPG 모션 보정 알고리즘으로 활동 후 데이터도 처리 가능* [[1]](#ref1)*)*

**촬영 위치에 대해**
> "어디서나 촬영 가능해요. 야외, 사무실, 어두운 방 — 모두 괜찮습니다. 앱이 조건을 자동으로 기록합니다."

---

### 7-3. 생리 주기 정보 입력 (PCOS 연구 필수)

> "촬영 전 오늘이 생리 주기 몇 번째 날인지 입력해 주세요. 잘 모르면 '모름'을 선택해도 됩니다."

- 이유: 피부 상태·피지 분비·염증이 주기에 따라 변화 → PCOS 그룹과 대조군의 주기 위상별 차이가 핵심 신호일 수 있음 [[15]](#ref15)
- 강요하지 않음: 모름 선택 시에도 촬영 진행 (결측 처리)

---

### 7-4. 온보딩 최소화 설계

엄격한 사전 훈련 대신, **촬영하면서 배우는 방식**으로 설계.

| 단계 | 내용 | 소요 시간 |
|------|------|---------|
| Day 0 | e-Consent (3분 영상 + 퀴즈 5문항) | 5분 | [[14]](#ref14) |
| Day 1 | 앱 설치 + 시범 촬영 1회 (결과 미사용) | 3분 | — |
| Day 2~ | 정식 촬영 (앱이 실시간 피드백 제공) | 1분/회 | — |

> **참조**: 짧은 온보딩이 장기 순응도에 유리함. Pratap et al.(2019)에서 복잡한 사전 훈련이 초기 탈락률을 높이는 것으로 나타남 [[16]](#ref16)
