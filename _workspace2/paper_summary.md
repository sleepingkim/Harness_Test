### [Process] 방법론

**데이터 수집 프로토콜:**
1. **Module A (rPPG-HRV)**: 60초 전면 카메라 촬영 → MediaPipe 468 랜드마크 → CHROM+DeepPhys 하이브리드 rPPG → SDNN/RMSSD/LF/HF/HFnu 산출 → SQI < 0.6 시 재촬영
2. **Module B (PCOS-DermScore)**: 주 1회 3방향 셀피 → 여드름(Faster R-CNN+LightGBM) + 다모증(ResNet50) + AN(CMYK) + 얼굴BMI(ResNet50) → 16차원 벡터
3. **Module C (월경 패턴)**: 일일 앱 입력 → LSTM(2층, 은닉 64) + TCN + Transformer → 16차원 벡터

**AI 모델 설계:**
- 입력: HRV 32차원 + DermScore 16차원 + Cycle 16차원
- 공유 임베딩: 64차원으로 투영
- Cross-Attention: 모달리티 간 쌍방향 어텐션
- 출력: 3-class softmax (PCOS / 자궁내막증 / 건강)
- 학습: 2단계 (개별 모듈 사전학습 → 전체 End-to-End 파인튜닝)

**검증 코호트:**
- Phase I: 파일럿 150명(6개월)
- Phase II: 검증 600명(12-18개월, 메타분석 효과크기 기반 표본수 산정)
- Phase III: 외부 검증 300명(6개월, 다기관)

## E — Extend: 비전문가를 위한 맥락 보충

### 왜 이 연구가 중요한가?

- 자궁내막증 환자는 평균 20대 초반부터 증상이 시작되나, 30대에야 확진되는 경우가 많음
- 진단을 위해 현재는 복강경 수술(전신마취 필요)이 사실상 유일한 금표준
- PCOS는 혈액검사 + 초음파가 필요하며, 건강보험 적용 국가에서도 여러 차례 외래 방문 필요
- 스마트폰은 이미 전 세계 69억 명이 보유 → 의료 인프라 없는 지역에서도 접근 가능

### 세 가지 측정 방식의 직관적 이해

| 모듈 | 무엇을 측정하는가 | 왜 의미 있는가 |
|------|-----------------|--------------|
| rPPG-HRV | 얼굴 색깔 변화로 심박 리듬 포착 | 두 질환 모두 자율신경계를 교란함 |
| 피부 분석 | 여드름·다모증·피부색 변화 탐지 | PCOS의 안드로겐 과잉이 피부에 드러남 |
| 월경 패턴 | 주기 불규칙성·통증 패턴 추적 | PCOS=불규칙 주기, 자궁내막증=통증 패턴 |

## 결론 (1문장)

스마트폰 카메라의 rPPG-HRV·피부 영상·월경 패턴 데이터를 Cross-Attention Fusion으로 통합하면, 침습적 검사 없이 PCOS와 자궁내막증을 조기 선별하는 실현 가능한 경로를 제시할 수 있으며, 이는 수억 명 여성이 겪는 7-10년 진단 지연 문제에 대한 형평성 있는 해법이 된다.
