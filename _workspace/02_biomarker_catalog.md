## 2. 데이터 계층별 요약

### Layer 1 — 생리 추적 앱

**업체 요청 대상**: Clue, Flo, Natural Cycles, Apple Health

| 바이오마커 | 업체 보유 현황 | 데이터 제안서 요청 근거 |
|---|---|---|
| 월경주기 패턴 | Clue 117M+ 이벤트, Flo 1.5M+ 사용자 | 양 질환의 가장 강력한 1차 디지털 바이오마커. ML 모델 핵심 입력 변수로 이미 검증됨 |
| 출혈 기간/양 | Clue, Flo 기본 추적 항목 | 과다/과소 월경 패턴이 자궁내막증·PCOS 감별 보조; 추가 비용 없이 기존 데이터 활용 가능 |
| 증상 동반 기록 | Clue, Flo 부가 기능 | 통증·기분·에너지 병행 기록이 ML 성능 향상에 기여 (Sivajohan et al., AUC 0.94) |
| 배란 예측 데이터 | Clue, Flo, OvuSense 알고리즘 산출 | PCOS 환자에서 무배란/지연배란 탐지 핵심. 주기 길이 >35일이 주요 예측 인자 |

**계층 총평**: 가장 높은 실현성. 대규모 코호트(수십만~수백만)가 이미 존재하며 비식별화 데이터 공유 선례가 있음. 데이터 제안서의 **1순위 요청 대상**.

---

### Layer 2 — 웨어러블 센서

**업체 요청 대상**: Oura, Apple (HealthKit), Garmin, Whoop, Fitbit, Ava/femSense

| 바이오마커 | 업체 보유 현황 | 데이터 제안서 요청 근거 |
|---|---|---|
| HRV | Oura, Apple Watch, Garmin, Whoop 상시 측정 | 양 질환에서 자율신경계 불균형 확인. 연속형·고해상도 시계열로 AI 모델 최적 |
| 연속 피부/체온 | Oura Ring, Ava, femSense | 배란 탐지(민감도 62%) 및 PCOS 온도 상승 지연 패턴 확인. 야간 연속 데이터로 주기 위상 추정 가능 |
| 액티그래피 | Apple Watch, Fitbit, Garmin | 자궁내막증 피로-활동 음의 상관 확인(Hillman 2025, n=68). 종단 추적에서 증상 중증도 궤적 반영 |
| 수면 패턴 | 위 기기 모두 | 자궁내막증 수면 장애, PCOS 수면무호흡 관련. 액티그래피와 동일 센서에서 추출 가능 |
| 호흡수 | Oura, Whoop, Garmin | 월경주기 변화 반영 가능성 있으나 독립적 연구 부족. **탐색적 마커**로 요청 시 추가 비용 없음 |

**계층 총평**: Layer 1 다음으로 높은 실현성. 연속형·고해상도 시계열 데이터로 AI 모델 성능 극대화. Oura/Apple은 연구 파트너십 프로그램 운영 중. 데이터 제안서 **2순위**.

---

### Layer 3 — 자가보고/증상 일지

**업체 요청 대상**: Phendo, ESD/EIS 개발팀, Clue/Flo (증상 기록 모듈)

| 바이오마커 | 업체 보유 현황 | 데이터 제안서 요청 근거 |
|---|---|---|
| 골반통/월경통 일일 점수 | Phendo, ESD(FDA PRO 준수) | 자궁내막증 ML 모델에서 가장 높은 예측력(XGBoost F1=0.92). 표준화된 PRO 도구 존재 |
| PCOS 증상 (팽만감, 다모증 등) | Clue 적응형 질문지 | Clue의 PCOS 리스크 스코어 기반. 환자 62-75%가 추적이 진단에 도움이 되었다고 보고 |
| 피로도/기분/스트레스 | 다수 건강 앱 | Layer 2 데이터와 병행 시 주관-객관 융합 가능. 단독으로는 낮은 특이성 |
| 성교통/배변통/배뇨통 | ESD, 연구 전용 설문 | ML 모델에서 중요 예측 인자이나 민감 정보로 수집률 낮음. **연구 설계 시 윤리 검토 필수** |

**계층 총평**: Layer 1·2와 결합할 때 시너지 극대화. 독립 사용 시 데이터 완결성과 편향이 주요 제한점. 데이터 제안서에서 **결합 요청** 권장.

### Layer 4 — 임상 참고

**업체 요청 대상**: 해당 없음 (병원/연구기관 직접 수집)

| 바이오마커 | 데이터 제안서 관련성 | 비고 |
|---|---|---|
| CA125 + NLR | 낮음 — 병원 전용, 디지털 앱/기기 업체 요청 불가 | RF 모델 AUC 0.85이나 혈액검사 필수 |
| 호르몬 패널 | 낮음 — Rotterdam 기준 필수 항목이나 웨어러블 대체 불가 | 디지털 대리지표(주기 불규칙성) 활용 우선 |
| 초음파 영상 + AI | 낮음 — 병원 전용, 그러나 AI 영상분석 협업 가능성 있음 | CNN 기반 자동 분석 연구 진행 중 |
| 유전자 발현 프로파일 | 매우 낮음 — 조직 생검 필요 | 임상 적용까지 거리 있음; 5-gene AUC 0.836 |
| HOMA-IR | 낮음 — 혈액검사 필수 | 교감 과활성과 상관. 웨어러블 HRV가 간접 대리지표 가능성 |
| EHR 기반 ML | 중간 — 전자건강기록 보유 기관 협업 필요 | XGBoost 정확도 93.15%. 대규모 후향적 데이터 확보 시 유용 |

**계층 총평**: 업체 데이터 요청 범위 밖. 단, Layer 1-3 데이터의 **검증 기준(Gold Standard)**으로 임상 데이터 일부 확보 필요. 공동연구 설계 시 참고.

## 7. 연구 부족 Known 마커 (Novel 에이전트 참고용)

다음 마커들은 이론적·간접적 근거가 존재하나 자궁내막증/PCOS 맥락에서 체계적 검증이 부족하여 novel-proposer가 신규 바이오마커 제안의 출발점으로 활용할 수 있다.

| 마커 | 현재 근거 수준 | 연구 부족 내용 | Novel 방향 제안 |
|---|---|---|---|
| **호흡수 (Respiratory Rate)** | 상용 웨어러블 측정 가능, 자궁내막증/PCOS 관련 연구 전무 | 월경주기에 따른 호흡수 변화 가능성은 체온·HRV 유사 메커니즘으로 추론 가능하나 직접 연구 없음 | 웨어러블 호흡수 시계열과 월경주기 위상/질환 상태 간 상관 탐색 |
| **SpO2 (혈중 산소 포화도)** | 상용 웨어러블 측정 가능, 부인과 질환 관련 연구 전무 | 야간 SpO2 변동이 PCOS 관련 수면무호흡과 연관될 수 있으나 검증 없음 | PCOS 환자의 야간 SpO2 패턴과 수면 단계별 변화 종단 분석 |
| **간질액 기반 비침습 호르몬 모니터링** | SMHMP 패치 파일럿(배란 예측 92.3%), 상용화 전 | 에스트로겐/프로게스테론 연속 측정이 가능하나 대규모 검증 없음 | 패치 기반 호르몬 시계열 + 기존 웨어러블 데이터 융합 모델 |
| **두 질환 동시 감별 모델** | 공통 바이오마커(HRV, 주기 패턴) 존재하나 감별 모델 부재 | 자궁내막증과 PCOS를 동시에 분류하는 통합 모델이 보고되지 않음 | 공통 디지털 바이오마커의 질환별 패턴 차이를 이용한 멀티클래스 분류기 개발 |
| **PCOS 종단적 HRV/체온** | 단면 연구만 존재 | PCOS 환자에서 웨어러블 장기 사용 전향적 코호트 연구 부재 | 3-6개월 종단 웨어러블 추적으로 PCOS 진행/호전 패턴 식별 |
| **사전예측(Presymptomatic Prediction)** | 현재 모델은 횡단적 분류(진단 보조)에 초점 | 증상 발현 전 사전 예측 가능 여부에 대한 종단적 검증 미흡 | Layer 1+2 종단 데이터에서 진단 전 잠복기 패턴 탐색 |
| **다인종/다민족 집단 검증** | 서구권 사용자 중심 데이터 | 아시아·아프리카 등 다양한 집단에서 디지털 바이오마커 유효성 미검증 | 글로벌 앱 데이터의 지역별 하위분석 또는 다국적 코호트 설계 |
