// 슬라이드 전환 후 클러스터 다이어그램 중심(파란 표준명)을 가리키며 //

서울시 공구대여 서비스 데이터베이스에는 표준 공구명이 **160종** 있습니다.

이 비표준화는 재고 집계와 통계, 검색 전체를 망가뜨립니다.

## 🎤 Slide 2 — Five Error Patterns `⏱ 0:55`

// 막대 차트를 위에서 아래로 훑으며 //

457건의 비표준 표기를 전수 분석하니,
상위 5개 유형이 전체의 **78%**를 차지했습니다.

오탈자, 브랜드 혼입, 동력원 명시, 영문 약어, 속성 기입.

그런데 이 중 어느 것도 단순한 규칙으로는 해결되지 않습니다.

// 빨간 강조 박스로 이동하며, 속도를 늦춰 또렷하게 //

특히 *기리, 뺀치, 함마* —

이건 일제강점기 이후 산업 현장에 남은 일본어 잔재입니다.
한국어와 음운 체계가 완전히 달라서,
동의어 사전 없이는 자동화가 불가능합니다.

...that's why we designed a three-component RAG pipeline.

---

## 🎤 Slide 3 — RAG v2 Pipeline `⏱ 1:30`

// 파이프라인 화살표를 왼쪽부터 손으로 따라가며 //

저희 파이프라인은 입력된 공구명이 들어오면,
먼저 검색 단계에서 표준명 후보 15개를 뽑습니다.

임베딩은 한국어 특화 **BGE-m3-ko**, 검색은 BM25와 FAISS를 결합한 하이브리드 방식입니다.

LLM이 후보 중 하나를 선택하고, 실패하면 Fallback이 자동으로 1위 후보를 반환합니다.

// 비교표의 BGE-m3-ko 행 ★을 가리키며 //

베이스라인과 가장 큰 차이는 바로 이겁니다.
MiniLM 384차원에서 BGE-m3-ko **1024차원**으로.
이 임베딩 교체 하나가 핵심입니다.

...let me show you what this pipeline achieved.

---

## 🎤 Slide 4 — The Verdict `⏱ 2:10`

// 슬라이드 전환 직후, 1~2초 침묵하며 청중과 눈 맞춤 //

[ 침묵 ]

***88.47%.***

// 천천히, 또렷하게 //

파라미터 4B짜리 소형 모델 gemma4:e4b가 달성한 정확도입니다.

// 회색 막대를 가리키며 //

RAG 없이 LLM만 단독으로 썼을 때는 *9에서 27%*에 불과했습니다.

// 파란 막대와 브래킷을 가리키며 //

RAG를 붙이는 순간 ***61에서 70 퍼센트포인트***가 뛰었습니다.

RAG는 선택이 아닙니다 — **필수**입니다.

// DeepSeek 박스로 이동 //

한 가지 더.
DeepSeek 모델은 한국어 자유 생성 능력이 **0%**였습니다.
그런데 RAG를 붙이자 *78.05%*를 달성했습니다.

RAG가 언어 능력 자체의 한계를 우회한 겁니다.

...and the key driver is not the LLM size — it's the embedding.

---

## 🎤 Slide 5 — Embedding Matters Most `⏱ 2:40`

// 비교표 화살표를 손으로 따라가며 //

같은 LLM, 같은 데이터, 파이프라인만 바꿨습니다.

granite 모델은 *55%에서 82%로*, deepseek-r1 8B는 *55%에서 78%로*.
*22에서 27 퍼센트포인트* 상승입니다.

// 요인 분해 막대에서 가장 긴 파란 막대를 가리키며 //

이 향상의 대부분, 약 15~20pp는
**임베딩 교체 하나**에서 나옵니다.

모델 크기보다 임베딩 선택이 먼저입니다.

...so here's what we've learned.

---

## 🎤 Slide 6 — Conclusion `⏱ 3:00`

// 세 불릿을 하나씩 포인팅하며, 빠르고 명료하게 //

세 가지만 기억해 주십시오.

**RAG는 필수** — 정확도가 61~70pp 상승합니다.

**소형 모델로 충분** — 4B gemma4가 88%를 달성합니다.

**임베딩이 먼저** — BGE-m3-ko 교체만으로 22~27pp.

// 빨간 박스를 짧게 가리키며 //

일본어 잔재 오류율 47%는 아직 과제로 남아 있습니다.

[ 침묵 ]

// 클로징 박스를 가리키며, 천천히 또렷하게, "Thank you" 없이 마무리 //

*"Privacy-safe, cost-effective, and fully deployable on-premise."*
