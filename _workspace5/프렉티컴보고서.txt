SUMMARY

In the digital age, data quality is a key element of a company’s
operation, but unstructured categorical data generated during manual
input often exists in the form of inconsistent ‘dirty data’, which hinders
the efficiency of data analysis and incurs enormous operation costs. In
particular,

lexical

diversity,

which

expresses

the

same

meaning

differently, distorts the category recognition ability of machine learning
models and is a major cause of performance degradation. To solve this
problem, this study proposes a semantic standardization methodology of
unstructured categorical data using a large-scale language model(LLM).
By standardizing LLM-based, we intend to automate the
process

and

maximize

efficiency.

In

this

data cleaning

methodology,

various

open-source LLM models were used to significantly improve the
consistency of data and significantly improve classification accuracy
compared to existing simple matching-based methods. In conclusion, a
standardization framework using LLM’s ability to understand the
meaning is expected to make a practical contribution to reducing the
time

and

cost

of

data

cleaning

and

increasing

data-based

decision-making and machine learning model reliability. In this study,
an

efficient

approach

in

the

field

of

unstructured

data

quality

management is presented, focusing on the tool name data used in
industry.

Key words : Unstructured data, Data standardization, Large language
model, Semantic Standardization, Data quality

I. 서 론
1.1. 연구 배경 및 문제 제기
디지털 전환 시대에서 데이터는 기업 운영의 핵심 자산으로 부상하
였다. 그리고 데이터의 가치는 근본적으로 그 데이터의 품질에서부터
시작된다. 그러나 현실에서 사용되는 데이터는 보통 불완전하고 비일
관적인 ‘더티데이터’ 형태로 존재한다. 이는 데이터 분석가로 하여금
업무를 진행하는 데 있어서 효율성 측면에서 심각한 병목 현상을 일
으킨다. 실제로 데이터 분석가들은 실제 분석 시간에서 50~80%에 달
하는 시간을 데이터 수집, 정제, 전처리 등비 작업에서 사용하고, 이
는 데이터 기반 의사결정의 신속성을 저해시키는 요소로 작용한다
(Wang et al., 2025 [4]; Kim et al., 2025 [18]; Keeney, 1975 [19]). 특
히, 다수의 사용자가 수동으로 입력하는 비정형의 범주 데이터는 데
이터 정제 과정의 난이도를 증가시킨다. 예를 들어, ‘충전식드릴’, ‘드
릴(배터리)’나 ‘드릴비트’, ‘기리’같이 동일한 의미를 지닌 공구 이름을
다른 어휘로 표현하는 문제는 데이터 정제 과정의 난이도를 증가시킨
다(Belcak et al., 2025 [7]; Hwang et al., 2025 [9]; Zhang & Huang,
2024 [12]). 이러한 데이터의 비일관성은 기계 학습 모델링 시 각각의
데이터를 완전히 다른 범주로 인식하게 만든다. 그 결과, 실제로는 몇
개 안 되는 핵심 개념이 여러 개의 무의미한 범주로 분열되는 현상이
발생한다. 이러한 현상은 머신러닝 모델에서 범주형 데이터를 수치화
된

방식으로 변경하는

방법

중

하나인

원

핫 인코딩(One-Hot

Encoding) 과정 수행 시 고차원의 희소행렬을 생성한다. 이는 모델의
훈련 시간과 메모리 요구량을 급증시키고 결국에는 과적합을 유발하
여 일반화 성능을 저해한다(정선우 외, 2023 [14]). 따라서 데이터 분
석과 데이터 기반 의사결정을 위해서는 데이터의 정제 과정에서 의미
론적 ‘더티데이터’ 문제를 근본적으로 해결하는 것이 중요하다.

1.2. 기존 방식의 한계점 및 해결책 제시
가. 기존 방식과 한계점
기존의 전통적 접근 방식에서는 정규식이나 Okt, KoNLPy와 같은 전
통적인 자연어처리 라이브러리 기반의 규칙을 정의해 문제를 해결하

- 1 -

고자 하였다. 그러나 단어 자체에서 예측가능한 구문론적(Syntactic)
오류 처리에 대해서만 한정적인 효율을 보이고, 의미론적(Semantic)
맥락을 이해하지 못한다(Dhakal et al., 2025 [3]; Zhang & Huang,
2024 [12]). 이들은 ‘충전식드릴’과 ‘드릴(배터리)’의 동력원이 충전을
필요로 하는 배터리로 작동하는 드릴임을 추론하거나, 공구 이름 필
드에 ‘글루건&심’과 같은 맥락 파악이 필요한 값에 대해서 판단하지
못한다(Glock & Korom, 2025 [10]). 결국 분석가는 예측 불가능한 수
많은 예외 케이스 문제를 해결하기 위해 경험 기반의 수작업에 의존
하게 된다(Wang et al., 2025 [4]). 이는 분석 과정의 재현성과 결과의
신뢰도를 저해하게 된다.
나. LLM을 활용한 해결책 제시
최근 거대 언어모델(LLM)이 발달하면서 데이터의 의미론적 맥락을
이해하고 추론하는 능력이 데이터 정제 분야에서 새로운 해결책으로
제시되고 있다. LLM은 단순한 패턴 찾기의 수준을 넘어서, 인간의
언어처럼 맥락과 데이터의 겉으로 드러나지 않는 의도를 파악하여 일
관적인 표현들을 표준화할 가능성을 갖고 있다. 이는 수작업이나 사
전 정의된 규칙 없이 비정형 범주형 데이터를 표준화할 수 있는 가능
성을 보여준다(Glock & Korom, 2025 [10]; Nguyen et al., 2023 [15];
Wong et al., 2025 [1]).

1.3. 연구목적
본 연구에서는 LLM의 의미론적 추론 능력을 활용하여, 공구 이름
더티데이터셋에 기입된 다양한 표현방식에서 의미를 자동으로 탐지하
고 표준화하는 지능형 데이터 정제 알고리즘을 설계하여 프로세스 효
율성과 데이터 품질의 두 관점에서 효과성을 실증적으로 검증하고자
한다. 세부 목표는 다음과 같다.
가. 프로세스 효율성 검증
데이터 정제에 소요되는 총 생성 시간(토큰 생성 시간으로 한정하여
측정)을 측정하여 제안하는 알고리즘의 생산성 수준을 정량화한다.
나. 데이터 품질 향상 검증
정제 결과물의 정확도(Accuracy), 의미론적 유사도(Semantic Similarity)
를 비교해봄으로써 데이터 품질 개선 효과를 확인한다.

1.4. 학문적 및 실증적 기여
핵심적인 학문적 기여는 다음과 같다.
첫째, 데이터 분석 업무의 기본 전제인 ‘원데이터의 불완전성 및 정
제 필요성’에 대한 기술적 해결책을 제시한다. 원데이터 수집 및 작성
업무를 맡는 ‘사람’에 의한 데이터 입력 과정의 수많은 오류를 최신
AI 기술을 활용하여 해결하는 데 이 연구의 의미가 있다. 특히, 공구
이름 데이터는 이러한 인적 오류가 집약된 굉장히 ‘더러운’ 데이터이
다. 이러한 데이터에 LLM을 적용해 각 모델 별 정제 정확도 및 총
생성 시간을 확인함으로써 데이터정제 과정에서 사용될 수 있는 효율
적인 LLM모델을 선택하기 위한 방향을 제시한다.
둘째, 데이터 정제를 ‘구문적 규칙 설계’ 작업에서 LLM을 활용한
‘의미론적 추론’ 작업으로 전환하는 새로운 패러다임을 ‘RAG 및
Few-Shot 기반의 LLM 정제’라는 구체적이고 재현 가능한 알고리즘으
로 제시한다(Wong et al., 2025 [1]; GAN et al., 2025 [6]).
이로써 기존 데이터 정제 연구가 규칙 기반 시스템의 취약성이나 지
도 학습의 레이블링 데이터 의존성 등의 한계를 보인 점을 극복하고
자 한다.

II. 관련 연구 및 데이터 문제 정의
2.1. 데이터 표준화 최신 연구 동향
기존 데이터 정제 방식에서의 한계를 극복하기 위해 LLM 기반의
데이터 표준화(LLM-based Data Standardization)가 다수 연구되고 있
다. LLM은 데이터의 의미를 이해하고 추론하는 능력을 바탕으로, 비
정형 텍스트 데이터를 표준화하는 데 효과적이다. 초기에는 주로
Few-Shot 방식의 예시기반 학습 방식을 사용했다. Few-Shot 방식은
모델이 프롬프트 내에 포함된 제한적인 고품질 예시(Shot)를 참고하여
복잡한 규칙을 학습하도록 유도한다. 하지만 Few-Shot 방식의 경우
몇 개의 예시를 통해 LLM 모델 자체의 일반적인 성능을 보조할 뿐
다수의 공구 이름 데이터와 같은 특정 분야의 모델에는 정확도가 낮
고 프롬프트 길이가 길어짐에 따른 비용이 증가하는 문제가 있다.

- 3 -

2.2. 외부데이터를 이용한 RAG 기술 활용
본 연구에서는 공구 이름이라는 특화된 도메인의 데이터 정제를 위해
LLM을 활용한 검색 증강 생성(RAG, Retrieval-Augmented Generation)
방식을 적용해보고자 한다. LLM 자체에서 학습된 데이터 외 외부 자
료로부터 만들어진 벡터데이터베이스를 검색하여 LLM에 프롬프트 맥
락을 제공함으로써 모델 자체 능력과 외부 지식을 결합하여 정제 정확
도를 극대화할 수 있는 방식이다. Few-Shot 방식에서 프롬프트 내에
입력된 제한된 예시만으로 복잡한 규칙을 학습하는 것을 넘어서 사용
자가 다루고자 하는 도메인에 특화된 맥락을 참조하여 성능을 향상시
킬 수 있다(Ovadia et al., 2024 [16]; Amugongo et al., 2025 [5];
Campo et al., 2025 [8]).

2.3 실험데이터 셋 구축 및 더티데이터 분석
가. 데이터셋 구축 및 정답지 확보
먼저 연구에 사용할 ‘더티데이터’를 확보하였다. 공공데이터포털에서
‘서울시 대여 공구 찾기 정보’ 데이터셋을 사용하였으며, 이 데이터셋
은 각 지역에서 대여 가능한 공구에 대한 정보를 포함하고 있다. 특
히 ‘공구이름’ 컬럼은 비정형적이고 비일관적인 입력으로 인해 ‘더티
데이터’가 다수 포함되어 있다. ‘공구이름’ 칼럼의 총 11,526행 원본
더티데이터 중 중복을 제거한 3,352개의 고유한 공구 이름 문자열을
최종 분석 대상으로 사용되었다.
나. 더티데이터 유형 분류
연구 대상이 된 공구이름의 정제 전 데이터 칼럼의 비일관성을 체계적
으로 분석하기 위해, 더티데이터의 유형을 5가지 대분류와 13가지 세부
유형으로 구성된 종합 분류표를 정의하여 [표1]에 나타내었다. 이 분류
표는 LLM 기반 정제 시스템이 해결해야 할 구체적인 문제의 복잡성을
보여준다(Saparina & Lapata, 2024 [11]; Karaca, M. F., 2024 [13]).

III. 제안 방법론 및 실험 설계
데이터 정제의 기술적 흐름을 명확히 하고, Few-Shot 및 RAG 방식을
활용한 LLM 기반 의미론적 표준화 알고리즘의 구체적인 설계 및 구현
과정을 기술한다.

3.1. 더티 데이터셋 준비 및 정답지 데이터셋 구축 과정
가. 더티데이터 필터링
데이터 분석의 효율성을 위해 공공데이터포털에서 가져온 ‘서울시
대여 공구 찾기 정보.csv’ 원본 11,526개 더티데이터 중에서 중복되는
공구 이름을 제거하여 3,352개의 고유한 더티데이터 셋을 최종 실험
대상으로 확보하였다.
나. 정답지 데이터셋 구축
성능 평가의 기준으로 사용된 ‘정답지’ 데이터셋은 다음 세 가지 요
소를 참고하여 연구자가 수동으로 일일이 확인하고 정리하였다.
분류 참고 자료 : 앞서 분류한 13개의 더티데이터 상세 분류 유형,
공구 이름이 작성된 카탈로그, 그리고 네이버 어학사전 등을 참고하
였다.
표준화 기준 : 공구의 기능적 측면을 중심으로 분류하였다.
핵심 정보 반영 : 정답지 작성 시, 동력원(에어, 전동, 충전식 등)의
여부, 세트 여부, 공구 유형 및 핵심 용도를 중심으로 정리하여, 작업
자가 공구 탐색 시 중요하게 여기는 정보를 최대한 반영하였다.
(Christian, N., & Okorie, C., 2013 [17])
3,352개 중 2,330개의 더티 데이터를 확인하였고, 제시된 3가지 기준
에 따라 386개의 정답데이터셋을 확보하였다.

3.3. LLM 프롬프트 설계 및 작동 메커니즘
데이터 정제를 위한 프롬프트는 LLM에게 ‘한국어 하드웨어 공구 이
름 분류전문가’의 역할을 부여하고, 구조화된 JSON 출력을 요구하였다.
가. Few-Shot 프롬프트 설계
Few-Shot 프롬프트는 모델 자체에 학습된 지식 기반 추론 능력을 테
스트하기 위한 대조군으로 설계되었다.
핵심 규칙 : 표준어 변환(예: ‘기리’ => ‘드릴비트’), 원본 단어 금지,
‘Preprocessed_Name(정제완료된

공구이름

칼럼)’의

띄어쓰기

금지,

JSON 전용 출력 요구.
생성 예시 : 프롬프트 내에 6개의 예시를 명시하여, 모델이 ‘함마’ =>
‘해머’, ‘충전’ => ‘무선’, 속성 분리 등을 학습하도록 유도하였다.
작동 방식 : LLM은 이 예시들의 맥락을 파악하여 입력 정답지 데이터
에 대한 정제 규칙을 추론하고 JSON을 출력한다.

나. RAG 파이프라인 및 메커니즘
RAG 방식은 Few-Shot 방식의 도메인 지식 부족 한계를 극복하기
위해, 외부의 ‘정답지’ 데이터를 LLM에 활용하도록 검색 증강하는 방
식으로 구현되었다.
임베딩 및 벡터 데이터베이스 구축 : 연구자가 제작한 386개의 공구
이름 정답지 데이터셋을 Sentence Transformer 모델을 사용하여 벡터
화를 진행했다. 벡터화된 정답지 데이터는 FAISS 벡터 데이터베이스
에 저장되었다.
검색 증강 : 3,352개의 더티데이터셋 입력마다 FAISS 벡터 데이터베
이스에서 가장 유사한 사례 3개를 유사도를 기준으로 검색했다. 유사
한 사례 개수는 토큰 생성 속도와 정확도를 고려하여 임의의 숫자 3
개로 설정하였다.
LLM 호출 및 프롬프트 입력 : 검색된 유사 사례 3개는 RAG 프롬프
트 템플릿의 {context} 변수에 입력된다. RAG 프롬프트는 Few-Shot과
달리 명시적인 예시를 포함하지 않았다. 대신 LLM에게 “정답 데이터
베이스”의 검색 결과를 최우선으로 참고하여 JSON을 생성하도록 명
시적으로 요구했다. LLM은 제공된 외부 도메인 지식을 기반으로
Preprocessed_Name, Brand, Power_Source, Specification의 속성명으로
지정하여 4가지 칼럼으로 구성된 JSON 출력을 생성한다. 각각 속성
정제 완료된 공구이름, 공구의 상표, 동력원, 길이/규격/용도/특이 사항
의 내용을 데이터로 갖는다.

후처리 및 결합 : LLM이 생성한 JSON 결과에서 정제 완료된 데이터
를 추출하여 기존의 더티데이터셋과 병합함으로써, 정제된 데이터셋
을 확보하였다. 이후 모든 비교를 위해 정답지 데이터와 정제완료된

그림 6. 방법론별 공구 이름 정제 정확도 비교 그래프
가. RAG 방식 평가
분석 결과, RAG 기반 LLM 모델들은 Few-Shot 방식 대비 압도적인
성능 우위를 보였다. Few-Shot Exaone 3.5:2.4b 모델의 정확도는
39.17%에 그친 반면, RAG 방식의 상위 모델들은 95% 이상의 매우
높은 정확도를 기록했다(최고 97.88%). 이는 비정형 범주형 데이터 표
준화와 같이 도메인 전문성이 요구되는 작업에서, 프롬프트 내 소수
의 예시만으로는 복잡한 의미론적 및 구문론적 규칙을 학습하기 어렵
다는 것을 보여준다. 반면, RAG는 외부의 ‘정답 데이터베이스’의 맥
락을 검색 증강하여 LLM에 제공함으로써, 모델 자체의 능력에만 의
존하는 것이 아니라 도메인에 특화된 외부지식을 활용하여 정제 작업
을 수행한다. 이 결과는 공구 이름 더티 데이터 정제에 있어 해당 도
메인 특화 지식의 검색 증강을 활용하여 정확도 높은 데이터 정제를
수행할 수 있음을 보여준다.
나. 모델 효율성 평가
RAG방식을 사용했을 때, Llama-3.2-Korean-Bllossom–gguf-3B:Q4_K_M
모델(파라미터 30억, 정확도 97.88%)과 Gemma3:4b 모델(파라미터 40
억, 정확도 97.58%)이 EXAONE-Deep-7.8B-GGUF:Q4_K_M모델(파라미
터 78억, 정확도 97.61%)과 유사한 정확도를 달성하였다. 또한 Exaone

- 13 -

3.5:2.4b 모델(파라미터 24억, 정확도 95.26%)보다 Gemma3:1b 모델(파
라미터 10억, 정확도 96.75%), EXAONE-4.0-1.2B-GGUF:IQ4_XS 모델

(파라미터 12억, 정확도 96.93%)의 정확도가 높다. 이 현상은 LLM의
모델 크기나 컴퓨팅 자원, 도메인 태스크 정확도 간의 상관관계가

RAG 환경에서는 약화됨을 의미한다. 즉, LLM의 임베딩/추론 능력이
충분히 뒷받침되고 검색 품질이 우수하다면, 상대적으로 작은 모델이라
도 대형 모델과 대등하거나 더 나은 성능을 낼 수 있다. 시스템의 생산
성 및 확장성 측면에서 경량 RAG 모델의 경제적 유효성을 보여준다.

RAG 메커니즘이 외부 도메인 지식을 LLM에 명시적으로 제공함으로
써, 모델 크기 자체가 주는 이점(방대한 일반 지식 기반 추론 능력)이
약화되고 성능이 평준화되었음을 보여준다. 결과적으로, 도메인 특화된
정제 태스크에서는 LLM의 규모보다 검색된 맥락 및 명령 이행 능력이
더 중요함을 의미한다.

표 7. 모델 우선순위 설정 기준
그리고 트레이드 오프를 계산하기 위해 더티데이터의 정제 정확도

델을 탐색해보았다(WINGPT Team, 2025 [2]).
Trade-Off Score = α x 정확도 - (1 - α) x 답변 생성속도
여기서 정확도와 비용은 모델의 정확도, 생성속도 최대치를 기준으
로 정규화된 값을 사용한다. 정확도의 경우 높을수록, 답변생성속도는
낮을수록 높은 Trade-Off Score를 갖는다. 가중치 α의 값에 따라 속도
중심 상황(α = 0.25), 균형 중심 상황(α = 0.5), 정확도 중심 상황(α =
0.75)으로 나타내었다.

가. LLM 강점 영역
상위 RAG 모델들은 특수기호, 운영용텍스트, 일본어잔재 유형에서
100%에 가까운 정확도를 기록했다. 운영용 텍스트는 심각한 노이즈에
도 불구하고 RAG 모델들은 이러한 노이즈를 식별하고 제거하는 데
매우 우수함을 확인하였다.
나. LLM 취약점 영역
유형별 정확도 분석 결과, 세트/구성품 유형은 모델에 따라 정확도가
하락하며 다른 유형에 비해 상대적으로 큰 취약점을 드러냈다. 이는
의미 모호성이 여전히 LLM 기반 시스템의 데이터 정제에 있어서 근
본적인 한계로 작용함을 시사한다.

4.5. LLM기반 정제 시스템의 실증적 의미
더티데이터 정제는 궁극적으로 데이터 분석의 성능을 향상시키기 위
한 전제 조건이다. LLM 기반 의미론적 표준화를 통해 의미적으로 동
일한 표현들이 하나의 표준 레이블로 완성되면, 원본 데이터의 불필요
한 카디널리티(Cardinality)가 크게 감소한다. 이는 데이터 기반 의사결
정의 신속성뿐만 아니라, 결과의 신뢰도(Data Quality) 측면에서 LLM
기반 워크플로우의 가능성을 제시하는 핵심적인 요소가 된다.

V. 결론
5.1. 연구 결과 및 시사점
비정형 범주형 공구 더티데이터의 의미론적 표준화 문제를 해결하기
위해 LLM과 RAG 기법을 활용한 알고리즘의 효과성을 정량적으로 검
증하였다.주요 연구 결과는 다음과 같이 요약할 수 있다.
첫째, LLM의 의미론적 추론 능력과 RAG의 도메인 지식 보강을 결합
한 방법론이 기존 Few-Shot 방식(39.17%) 대비 압도적인 정확도(최고
97.88%)를 달성함으로써, LLM 기반 데이터 정제 패러다임의 성공적인
전환 가능성을 확인하였다.
둘째, 경량 LLM 모델의 효율성을 확인하였다. RAG 환경에서 소형
모델이 대형 모델 이상의 성능을 발휘함에 따라, LLM 기반 시스템 설
계에서 컴퓨팅 자원의 한계를 극복하고 실용화 방향성을 제시하였다.
셋째, LLM은 메타데이터, 특수기호, 운영용 텍스트와 같은 노이즈를
높은 더티데이터를 정확도로 제거할 수 있음을 확인하였다. 이는 데이
터 품질을 근본적으로 상향 평준화시킴을 의미한다.

5.2. 제안 알고리즘의 기대 효과
데이터 분석 업무에서 기본 전제로 원데이터의 불완전성에 따라 정
제해야 하는 ‘사람’에 의한 데이터 입력 과정의 많은 오류들을 최신 AI
기술을 활용하여 접근해 보는데 의미가 있다. 특히 공구이름 데이터는
이러한 오류가 집약된 굉장히 ‘더러운’ 데이터이기 때문에, 이 데이터
를 정제하는 LLM의 정확도와 총 생성 시간(처리 속도)을 확인하는 과
정은 데이터 품질 확보의 중요성 보여준다. 이 알고리즘은 데이터 분석

- 21 -

가의 생산성을 극대화하고, 데이터 품질의 상향 평준화를 통해 데이터
기반 의사결정의 신뢰도를 높이는 실질적인 방법론을 제시하였다. 특
히, ‘생성 속도’와 ‘정확도’의 트레이드 오프를 통해 최적, 고성능, 최대
처리 세 가지 관점에서의 데이터분석 시스템 적용 방향을 제시함으로
써 학문적 및 실증적 기여를 할 수 있다.

5.3. 연구 한계 및 향후 연구 방향
본 연구는 LLM API 사용 시 발생할 수 있는 비용 및 지연 시간 문
제, 그리고 LLM의 환각(Hallucination) 현상으로 인한 오류 가능성 등
기존 LLM 기반 연구가 갖는 일반적인 한계를 공유한다. 특히, 연구자
가 수동으로 구축하고 수정한 정답지 데이터 및 더티데이터 유형 분류
과정이 실제 LLM 모델이 학습했을 빅데이터와 상이한 부분이 있었을
것으로 판단되며, 이는 정확도 측면에서 영향을 미쳤을 수 있다.
향후 연구는 다음과 같은 방향으로 진행될 필요가 있다.
첫째, 정제 과정에서 취약점을 보인 의미 모호형 데이터에 대해 LLM
의 추론 결과를 보강할 수 있도록 명시적인 비즈니스 규칙 또는 인간
피드백 루프(Human-in-the-Loop)를 시스템에 통합하는 연구가 필요하다.
둘째, RAG 시스템 구축 시 사용된 임베딩 모델 외 다양한 한국어 모
델을 활용하여 성능 및 효율성을 비교 분석함으로써, LLM 기반 표준
화 알고리즘의 일반화 가능성과 자원 효율성을 더욱 강화해야한다.
