## 정답지 V2 설계 철학

**사용자가 공구를 찾을 때 중요하게 여기는 5가지 정보 축:**
1. **standard_name** - 이 공구가 정확히 뭔가? (표준 명칭으로 통일)
2. **brand** - 어떤 브랜드인가? (보쉬, 디월트, 아임삭, 세신 등)
3. **power_source** - 동력원이 뭔가? (유선/충전식(무선)/에어/수동/배터리/가스)
4. **specification** - 크기/규격/모델번호 (mm, 인치, V, W, PCS 등)
5. **usage_note** - 용도/특성 (세트, 접이식, 가정용, 콘크리트용, 소모품 등)

### V2 CSV 구조 (6칼럼)

| 칼럼명 | 설명 | 예시 |
|--------|------|------|
| original_name | 원본 더티 데이터 그대로 | 보쉬 충전해머드릴(무선) |
| standard_name | 정제된 표준 공구명 | 충전해머드릴 |
| brand | 브랜드 (추출된 경우) | 보쉬(BOSCH) |
| power_source | 동력원 | 충전식(무선) |
| specification | 규격/모델번호 | 18V, GBH5-38X 등 |
| usage_note | 용도/특성/부가정보 | 콘크리트용, 세트, 접이식 등 |

### V2 데이터 구성 (총 639개)
- **Part 1** (497개): 실제 서울시 더티데이터 → 구조화된 정답 매핑
  - 동력원 구분이 중요한 드릴/드라이버 계열 집중 (100+개)
  - 브랜드 정보가 포함된 실제 사례 (보쉬, 디월트, 아임삭, 계양, 마끼다 등)
  - 규격/크기가 포함된 사례 (117개)
  - 용도/특성이 포함된 사례 (149개)
- **Part 2** (142개): 카탈로그/KS/순화 표준 레퍼런스
  - 상보 카탈로그 INDEX 기반 표준 공구명
  - KS B 표준 규격 엔트리
  - 일본어 잔재 → 표준 한국어 순화 사전
