# Paper Scan — 논문 할루시네이션 검토 스킬

인용된 논문들의 핵심 주장(정확도, AUC, 샘플 수, 저자, 연도 등)을 웹 검색으로 교차 검증하고, 할루시네이션 여부를 판정하여 엑셀/CSV로 저장한다.

## 실행 조건

`/paper_scan [파일경로]` 또는 `paper_scan` 단독 호출 시 실행.
- 파일경로 미지정 시: `_workspace/` 내 모든 `.md` 파일 대상
- 파일경로 지정 시: 해당 파일만 대상

## 작업 프로세스

### Step 1: 논문 목록 추출
- 대상 파일에서 인용된 모든 논문 정보 추출
  - 저자, 연도, 제목, 저널, URL
  - 인용된 핵심 주장: 정확도/AUC/F1/민감도/특이도, 샘플 수(n=), 연구 설계

### Step 2: 교차 검증 (논문당 WebSearch 1~2회)
각 논문에 대해:
1. 제목 + 저자로 검색하여 실제 존재 여부 확인
2. 핵심 수치(AUC, 정확도 등)가 원문과 일치하는지 확인
3. 저널명·연도·URL 정확성 확인

### Step 3: 할루시네이션 판정

| 판정 | 기준 |
|------|------|
| ✅ 검증됨 | 논문 실존 + 핵심 수치 일치 |
| ⚠️ 부분 불일치 | 논문 실존하나 수치/저자/연도 오류 |
| ❌ 할루시네이션 의심 | 논문 미발견 또는 주요 정보 불일치 |
| 🔍 검증 불가 | 페이월/접근 불가로 수치 확인 불가 (존재는 확인) |

### Step 4: 결과 저장
- `_workspace/paper_scan_result.csv` — 전체 결과 CSV (Excel 호환)
- 판정 요약을 터미널에 출력

## 출력 CSV 컬럼

```
번호, 논문제목, 저자, 연도, 저널, 인용수치, 검증결과, 판정, 비고, 원본URL
```

## 작업 원칙
- 검색 결과가 없다고 바로 할루시네이션으로 단정하지 않는다 — 2회 이상 다른 키워드로 재검색
- 수치 불일치는 반올림·단위 차이 가능성을 먼저 고려
- 판정 근거를 비고 컬럼에 반드시 기재
- 페이월로 전문 접근 불가 시 초록(abstract) 정보로 부분 검증
