# Reference Hallucination Guard

논문이나 보고서에 포함된 참고문헌의 실제 존재 여부를 검증하여
할루시네이션(허위 인용)을 탐지하고 분류한다.

## 목적

LLM이 생성한 문헌 탐색 결과에는 실제로 존재하지 않는 논문이 포함될 수 있다.
이 스킬은 각 참고문헌을 웹 검색으로 교차 검증하여 신뢰도를 평가한다.

---

## 검증 프로세스

### Step 1: 참고문헌 목록 추출

검증 대상 파일(`.md` 또는 보고서)에서 모든 참고문헌 항목을 추출한다.

추출 정보:
- 저자명
- 논문 제목
- 저널/컨퍼런스명
- 발행 연도
- DOI 또는 URL (있는 경우)

---

### Step 2: 검증 전략 (우선순위 순)

각 참고문헌에 대해 다음 순서로 검증한다:

**전략 A: DOI 직접 확인**
- DOI가 있는 경우: `https://doi.org/{DOI}` 접근하여 실제 논문 페이지 확인
- 응답이 있으면 ✅ 검증됨

**전략 B: 제목 + 저자 검색**
- Google Scholar, PubMed, Semantic Scholar, IEEE Xplore에서 검색
- `"{논문 제목}" {저자 성} {연도}` 쿼리로 검색
- 정확히 일치하는 제목 발견 시 ✅ 검증됨

**전략 C: 저널/컨퍼런스 교차 확인**
- 해당 저널/컨퍼런스의 공식 사이트에서 해당 연도 목차 확인
- 논문 제목이 목차에 있으면 ✅ 검증됨

---

### Step 3: 결과 분류

| 등급 | 기호 | 기준 |
|------|------|------|
| 검증됨 | ✅ | DOI 또는 공식 DB에서 실제 논문 확인 |
| 부분 검증 | ⚠️ | 저자/제목 일부 일치하나 세부사항 불일치 |
| 미확인 | ❓ | 검색 결과 없음, 접근 불가 |
| 할루시네이션 의심 | ❌ | 존재하지 않는 DOI, 저자명-제목 불일치, 저널 미존재 |

---

### Step 4: 할루시네이션 의심 신호

다음 패턴이 발견되면 ❌ (할루시네이션 의심)으로 분류:

- **DOI 오류**: doi.org 응답 없음 또는 다른 논문으로 연결
- **저자-제목 불일치**: 해당 저자가 해당 제목의 논문을 쓴 기록 없음
- **저널 불일치**: 해당 저널이 해당 연도에 해당 논문 게재 기록 없음
- **존재하지 않는 저널**: 저널명 자체가 검색되지 않음
- **연도 오류**: 저자가 해당 논문을 발표한 연도가 다름
- **URL 오류**: 제공된 URL이 다른 페이지로 연결되거나 404 반환

## 입력/출력 프로토콜

### 입력
- 검증 대상 파일 경로 (`.md` 파일)
- 또는 참고문헌 목록 직접 입력

### 출력
검증 결과를 두 가지 방식으로 제공:

**1. 인라인 표기**: 원본 파일의 각 참고문헌 뒤에 검증 기호 추가
```
Li et al., 2020, npj Digital Medicine ✅
Yang et al., 2022, Scientific Reports ⚠️ (저자명 불일치 가능성)
Unknown et al., 2021, Fake Journal ❌ (저널 존재하지 않음)
```

**2. 검증 요약 보고서**: `_workspace/camera/reference_validation_report.md`
```markdown
# 참고문헌 검증 보고서

## 검증 통계
- 전체 참고문헌: N개
- ✅ 검증됨: X개 (X%)
- ⚠️ 부분 검증: Y개 (Y%)
- ❓ 미확인: Z개 (Z%)
- ❌ 할루시네이션 의심: W개 (W%)

## 검증 결과 상세
| # | 참고문헌 | 검증 방법 | 결과 | 비고 |
|---|---------|---------|------|------|

## 할루시네이션 의심 항목 상세 분석

## 권장 조치
- 제거 권장 항목 (❌)
- 수작업 확인 필요 항목 (⚠️, ❓)
```

## 에러 핸들링

| 상황 | 처리 |
|------|------|
| 웹 검색 불가 | 검색 가능한 항목만 검증, 나머지 ❓ 표시 |
| DOI 접근 차단 | 제목 검색으로 우회, ⚠️ 표시 |
| 동명이인 저자 | 소속기관·공동저자로 교차 확인 |
| 비영어 논문 | 한국어 DB (KISS, RISS, NDSL) 추가 검색 |

---

## 주의사항

- 검증은 웹 검색 기반이므로 100% 정확성을 보장하지 않음
- ❓(미확인)이 ❌(할루시네이션)을 의미하지 않음 — 접근 제한 논문일 수 있음
- 최종 판단은 연구자가 직접 확인해야 함
