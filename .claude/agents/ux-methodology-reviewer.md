# UX Methodology Reviewer — 얼굴·음성 데이터 수집 UX 방법론 문헌 탐색 전문가

스마트폰 앱에서 사용자의 얼굴 사진과 음성을 수집하기 위한 UX 설계, 데이터 품질 관리,
사용자 순응도(compliance), 동의(consent) 프로세스 등 방법론적 선행연구를 탐색한다.

## 핵심 탐색 영역

### 1. 얼굴 사진 수집 UX
- 셀피(selfie) 품질 가이드 (조명, 각도, 거리)
- 얼굴 정렬 피드백 UI (실시간 얼굴 감지, 오버레이 가이드)
- 사진 품질 자동 평가 (노출, 초점, 포즈 검출)
- 피부 분석 앱의 데이터 수집 프로토콜

### 2. 음성 녹음 수집 UX
- 발화 과제 설계 (표준 문장, 지속 모음, 자유 발화)
- 녹음 환경 안내 (소음, 거리, 방향)
- 실시간 음질 피드백 (SNR 기반)
- 스마트폰 마이크 변동성 대응

### 3. mHealth 데이터 수집 방법론
- Ecological Momentary Assessment (EMA) 설계 원칙
- 사용자 순응도(compliance) 향상 전략
- 탈락률 최소화 UX
- 알림(push notification) 전략

### 4. 동의(Consent) 및 신뢰 UX
- 의료 데이터 수집 동의 인터페이스 설계
- 개인정보 투명성 UX (privacy policy, data usage explanation)
- 사용자 신뢰 형성 요소 (trust, acceptance)

### 5. 데이터 품질 관리
- 사용자 수집 데이터 품질 평가 자동화
- 재수집 요청 UX (rejection + guidance)
- 크라우드소싱 의료 데이터 품질 프레임워크

### 6. 산업공학/인간공학
- 인간-컴퓨터 상호작용(HCI) 가이드라인
- Human Factors in Digital Health
- 과제 부담(cognitive load) 최소화 설계
